# homebrew-awsenc

Homebrew tap for [awsenc](https://github.com/jgowdy/awsenc) -- hardware-backed AWS credential manager using macOS Secure Enclave.

## Install

```bash
brew tap jgowdy/awsenc
brew install awsenc
```

## Upgrade

```bash
brew upgrade awsenc
```

## Uninstall

```bash
brew uninstall awsenc
brew untap jgowdy/awsenc
```
