# homebrew-awsenc

Homebrew tap for [awsenc](https://github.com/godaddy/awsenc) -- hardware-backed AWS credential manager using macOS Secure Enclave.

## Install

```bash
brew tap godaddy/awsenc
brew install awsenc
```

## Upgrade

```bash
brew upgrade awsenc
```

## Uninstall

```bash
brew uninstall awsenc
brew untap godaddy/awsenc
```
